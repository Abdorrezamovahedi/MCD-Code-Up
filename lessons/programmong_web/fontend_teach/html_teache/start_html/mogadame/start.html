MCD

مقدمه (Introduction)

اینجا با «آموزش HTML مقدماتی» شروع می کنیم. HTML یعنی «Hyper Text Markup Language». یعنی زبان برچسب گذاری صفحات وب. «تگ (Tag)» یک برچسب است. «المان (Element)» یعنی تگ آغاز، محتوا و تگ پایان. با این ها صفحه می سازیم. مثل ساخت لگو اما برای وب.

HTML چیست؟

HTML اسکلت هر وب سایت است. مرورگر تگ ها را می خواند و نمایش می دهد. خود تگ ها دیده نمی شوند. فقط نتیجه دیده می شود.

نکته: «استاندارد (Standard)» یعنی قوانین رسمیِ ساخت. HTML5 آخرین نسل است.

یک سند ساده HTML

توضیح مثال

  1. <!DOCTYPE html> به مرورگر می‌گه که این صفحه با HTML5 ساخته شده و باید کدهای HTML رو با همین روش بخونه.
  2. <html> مثل یک ظرف بزرگ می‌مونه که تمام کدهای صفحه داخلش قرار می‌گیرن. یعنی هر چیزی که برای ساخت صفحه می‌نویسیم، بین این دو تگ قرار می‌گیره.
  3. <head> جاییه که اطلاعات و تنظیمات صفحه رو داخلش می‌نویسیم. مثلاً اسم صفحه، تنظیمات نمایش و اطلاعاتی که به مرورگر کمک می‌کنن صفحه رو درست نشون بده.
  4. <meta> به مرورگر یک سری اطلاعات درباره صفحه می‌ده. مثلاً بهش می‌گه از چه روشی برای نمایش نوشته‌ها استفاده کنه تا حروف فارسی و انگلیسی درست دیده بشن.
  5. <title> اسم صفحه رو مشخص می‌کنه. همون اسمی که بالای مرورگر، داخل تب صفحه می‌بینی.
  6. <body> قسمت اصلی صفحه است. هر چیزی که قراره کاربر ببینه، مثل نوشته‌ها، عکس‌ها، فیلم‌ها و دکمه‌ها، داخل این قسمت قرار می‌گیره.
  7. <h1> برای نوشتن عنوان اصلی صفحه استفاده می‌شه. مثلاً وقتی می‌خوایم بالای صفحه بنویسیم «آموزش HTML»، می‌تونیم از این تگ استفاده کنیم.
  8. <p> برای نوشتن متن‌های معمولی داخل صفحه استفاده می‌شه. مثلاً وقتی می‌خوایم درباره HTML توضیح بدیم، نوشته‌مون رو داخل این تگ قرار می‌دیم.

المان (Element) و تگ (Tag)

ببین، وقتی در HTML چیزی می‌سازیم، معمولاً از سه قسمت تشکیل می‌شه: تگ شروع، محتوا و تگ پایان. تگ شروع می‌گه که می‌خوایم یک بخش رو شروع کنیم، محتوا همون چیزیه که داخلش قرار می‌دیم و تگ پایان نشون می‌ده که کارمون با اون بخش تموم شده.

مرورگرها چه می کنند؟

مرورگر مثل مترجم است. تگ ها را می خواند و خروجی می سازد. تگ ها نمایش داده نمی شوند. فقط نتیجه نمایش می شود.

یعنی اول تگ شروع رو می‌نویسیم، بعد چیزی که می‌خوایم داخلش قرار می‌دیم و در آخر تگ پایان رو می‌نویسیم. این سه قسمت کنار هم یک المان رو می‌سازن.

مثلاً می‌تونی یک المان رو مثل یک جعبه تصور کنی؛ اول در جعبه رو باز می‌کنی، چیزی داخلش می‌ذاری و بعد درش رو می‌بندی. در HTML هم تقریباً همین اتفاق می‌افته!

المان‌های خالی (Empty Elements)

البته همه المان‌ها سه قسمت ندارن. بعضی از اون‌ها فقط یک تگ دارن و نیازی به تگ پایان ندارن. مثلاً تگ <br> باعث می‌شه نوشته به خط بعدی بره.

نکته: به این نوع المان‌ها، المان خالی (Empty Element) می‌گن؛ یعنی تگ پایان ندارن و برای انجام کارشون به محتوای داخل تگ نیازی نیست.

جمع‌بندی این درس

در مقدمه HTML دیدی صفحه از چه منطقی پیروی می‌کند و چرا تگ‌ها به مرورگر ساختار می‌دهند. این لایه مفهومی است؛ عجله برای تگ‌های زیاد بدون فهم سند HTML، معمولاً باعث اشتباه‌های تکراری می‌شود.

امید و ادامه

اگر بعضی اصطلاحات هنوز ته‌نشین نشده، طبیعی است. با یک‌بار نوشتن سند ساده در درس بعد، ذهنت مرتب می‌شود. در MCD Code Up مفاهیم روی هم چیده شده‌اند تا همین‌طور آرام جلو بروی.

این مسیر بخشی از آموزش رایگان برنامه‌نویسی در MCD Code Up است. اگر هنوز مسیرت را انتخاب نکرده‌ای، از راهنمای شروع کمک بگیر.

سؤال‌های متداول دربارهٔ این درس

تفاوت تگ و المان چیست؟

تگ معمولاً برچسب شروع/پایان است؛ المان اغلب کل واحد شامل تگ و محتوا را می‌گوید. در تمرین عملی تفاوت ملموس می‌شود.

باید نسخه خاصی از HTML یاد بگیرم؟

روی HTML رایج و استاندارد مدرن تمرکز کن؛ همان چیزی که مرورگرهای امروز پشتیبانی می‌کنند.

اگر چیزی کار نکرد چه؟

غلط املای تگ، تگ بسته‌نشده و باز کردن فایل اشتباه از خطاهای پرتکرار اول راه هستند؛ آرام بررسی کن.

یک نکته سئو برای تو

ساختار تیترها (h1 سپس h2) هم برای خواننده و هم برای درک موضوع توسط موتور جستجو مفید است. در تمرین‌هایت از تیتر تودرتوی بی‌نظم پرهیز کن.
