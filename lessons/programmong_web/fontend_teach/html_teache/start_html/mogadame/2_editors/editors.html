ما به تو در این قسمت می گیم که از چه برنامه هایی در ویندوز و ...(سیستم عامل های دیگر) می توانند کد های HTML خود را اجرا کنید تا سایت خود را بسازید و کیف کنید 😉 ⁂

برنامه های پیشنهادی ما برای سیستم عامل های ویندوز و...:

من به شما برنامه ای رو پیشنهاد می دم که اکثر برنامه نویسان حرفه ای از اون استفاده می کنند و این برنامه 👇
حرف نداره 😎

نکته: برنامه ای که ما معرفی می کنیم رو می توان داخلش HTML و CSS و JavaScript و تمام زبان های برنامه نویسی جهان حتی به غیر از سایت سایت سازی را کد نویسی کرد 😎

اون برنامه چیزی نیست جز:

اسم برنامه : VS Code

در این قسمت می توانید نسخه مناسب سیستم خود را انتخاب کنید. کارت های دانلود در کامپیوتر به صورت شبکه ای و در موبایل به صورت افقی قابل مشاهده هستند.

اگر نمی‌دانید کدام نسخه را دانلود کنید، معمولاً نسخه Windows User Installer x64 برای کامپیوترهای معمولی ویندوز مناسب است.

چرا VS Code را پیشنهاد می‌کنیم؟

  1. این برنامه برای نوشتن کدهای HTML، CSS و JavaScript بسیار مناسب است.
  2. می‌توان در آن پروژه‌های مختلف برنامه‌نویسی ایجاد کرد.
  3. افزونه‌های زیادی دارد که امکانات برنامه را بیشتر می‌کنند.
  4. محیط آن قابل تنظیم است و می‌توان ظاهر آن را تغییر داد.
  5. برای شروع یادگیری برنامه‌نویسی و توسعه پروژه‌های حرفه‌ای کاربرد دارد.
