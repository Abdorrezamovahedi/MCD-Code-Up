ویرایشگرها (Editors)

ما به تو در این قسمت می گیم که از چه برنامه هایی در ویندوز و ...(سیستم عامل های دیگر) می توانند کد های HTML خود را اجرا کنید تا سایت خود را بسازید و کیف کنید 😉 ⁂

برنامه های پیشنهادی ما برای سیستم عامل های ویندوز و...:

من به شما برنامه ای رو پیشنهاد می دم که اکثر برنامه نویسان حرفه ای از اون استفاده می کنند و این برنامه 👇
حرف نداره 😎

نکته: برنامه ای که ما معرفی می کنیم رو می توان داخلش HTML و CSS و JavaScript و تمام زبان های برنامه نویسی جهان حتی به غیر از سایت سایت سازی را کد نویسی کرد 😎

اون برنامه چیزی نیست جز:

اسم برنامه : VS Code

در این قسمت می توانید نسخه مناسب سیستم خود را انتخاب کنید. کارت های دانلود در کامپیوتر به صورت شبکه ای و در موبایل به صورت افقی قابل مشاهده هستند.

چرا VS Code را پیشنهاد می‌کنیم؟

  1. این برنامه برای نوشتن کدهای HTML، CSS و JavaScript بسیار مناسب است.
  2. می‌توان در آن پروژه‌های مختلف برنامه‌نویسی ایجاد کرد.
  3. افزونه‌های زیادی دارد که امکانات برنامه را بیشتر می‌کنند.
  4. محیط آن قابل تنظیم است و می‌توان ظاهر آن را تغییر داد.
  5. برای شروع یادگیری برنامه‌نویسی و توسعه پروژه‌های حرفه‌ای کاربرد دارد.

جمع‌بندی ویرایشگرها

ابزار خوب، یادگیری را تندتر و خطایاب را ساده‌تر می‌کند

جمع‌بندی این درس

ویرایشگر کد جایی است که می‌نویسی، ذخیره می‌کنی و پروژه را منظم نگه می‌داری. در این درس دیدی چرا به‌جای ابزارهای محدود، یک ویرایشگر مناسب مثل محیط‌های رایج توسعه انتخاب می‌کنی و چطور مسیر نوشتن HTML را هموارتر می‌کند.

درس و مسیر بعدی

حالا که ابزار آماده است، برو پایه‌های HTML">پایه‌های HTML و اولین تگ‌ها و ساختار صفحه را بنویس. اگر نیاز به مرور مفهومی داری به مقدمه HTML">مقدمه برگرد. برای دیدن ادامهٔ مسیر، سرفصل‌های HTML">سرفصل HTML را چک کن.

امید و ادامه

نصب و راه‌اندازی ویرایشگر یک پیروزی کوچک اما واقعی است. از اینجا به بعد هر تمرین در همان محیط ثبت می‌شود و پیشرفت را می‌بینی. MCD Code Up می‌خواهد همین جریان کار را برای تو ساده کند.

این مسیر بخشی از آموزش رایگان برنامه‌نویسی در MCD Code Up است. اگر هنوز مسیرت را انتخاب نکرده‌ای، از راهنمای شروع کمک بگیر.

سؤال‌های متداول دربارهٔ این درس

کدام ویرایشگر بهتر است؟

آن که ساده، رایگان و رایج باشد و با HTML راحت کار کند. مهم‌تر از برند، این است که هر روز در آن تمرین کنی.

نوت‌پد سیستم کافی است؟

برای آزمایش خیلی کوچک بله؛ برای یادگیری جدی، ویرایشگر کد با امکانات پایه راحت‌تر است.

باید همه افزونه‌ها را نصب کنم؟

خیر. اول ساده شروع کن؛ افزونه وقتی لازم شد اضافه می‌شود.

یک نکته سئو برای تو

نام فایل‌های پروژه را انگلیسی ساده و معنادار بگذار (مثلاً about.html). این عادت هم در کار تیمی و هم در آدرس صفحات وب برای سئو مفید است.
