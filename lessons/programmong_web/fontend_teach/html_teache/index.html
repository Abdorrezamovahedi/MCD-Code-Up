html چیست ؟

HTML زبانی است که تو اولین صفحه سایتت رو میسازی تا روی آن کار انجام بدی.

برای شروع:

  1. با قدرت شروع به کار کن و همه چیز رو بسپار به مغزت هدف تو برای کسی مهم نیست جز خودت
  2. کسی برای تو تلاش نمی کنه جز خودت پس اسمرار داشته باش
  3. اگر تصمیم گرفتی شروع کنی ،شروع کن و مثل مرد پای حرفت باش و ادامه بده خستگی جزوی از راهه.
  4. به ما اعتماد کن ما مثل مرد برای آموزش دادن به تو در این سایت وقت گذاشتیم پس برای شروع کلیک کن

جمع‌بندی این درس

اینجا نقطهٔ ورود به HTML است. قرار است با زبان نشانه‌گذاری صفحات وب آشنا شوی؛ زبانی که به مرورگر می‌گوید عنوان، پاراگراف، لینک و تصویر کجا هستند. بدون HTML، وب‌صفحه معنا ندارد.

امید و ادامه

اولین باری که یک عنوان را با تگ می‌نویسی و در مرورگر می‌بینی، حس «خودم ساختم» می‌آید. همان حس را جدی بگیر — موتور پیشرفت تو است. MCD Code Up برای همین لحظه‌ها طراحی شده است.

این مسیر بخشی از آموزش رایگان برنامه‌نویسی در MCD Code Up است. اگر هنوز مسیرت را انتخاب نکرده‌ای، از راهنمای شروع کمک بگیر.

HTML زبان نشانه‌گذاری است؛ ساختار را توصیف می‌کند. منطق پیچیده با زبان‌های برنامه‌نویسی مثل JavaScript می‌آید.

باید همه تگ‌ها را حفظ کنم؟

خیر. پرکاربردها را با تمرین یاد می‌گیری؛ بقیه را موقع نیاز در مرجع می‌بینی.

خروجی را کجا ببینم؟

فایل را در مرورگر باز کن. HTML برای دیده شدن در مرورگر نوشته می‌شود.
